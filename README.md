#UNI-AFYA
Student Health, Guidance and Counselling System

##
UNI-AFYA is a web based system designed to help university students 
access health services, guidance and counselling online.

##Features
- Student registration and login
- Health issue reporting
- Appointment booking
- Guidance and counselling requests

##Built with
- PHP
- MySQL
- HTML and CSS
- XAMPP
